# 三炮十五兵博弈分析系统

本项目是针对 5x5 棋盘规则开发的棋类模拟与博弈分析系统，集成了高性能博弈引擎、图形交互界面及完整的残局库支持。

## 系统特性

- **多模式对弈**：支持人机对弈、机器对弈及多人对弈模式。
- **高性能引擎**：核心算法基于 Cython 优化，采用 PVS、LMR 及置换表技术。
- **残局定解**：挂载 3 炮对 4 兵及以下规模的全集残局库，支持 DTM 极速推演。
- **数据管理**：支持 FEN 局面解析与 JSON 格式棋谱存储。
- **可配置化**：支持调整搜索深度、时间限制及 AI 策略权重。

## 游戏规则

### 棋盘布局
棋盘为 5x5 网格。初始布局包含 15 个兵（位于前三行）和 3 个炮（位于底线指定位置）。

### 移动逻辑
- **兵**：沿线条上下左右移动一格至空位。
- **炮**：沿线条移动一格至空位，或跳过一个空格由于吃掉对方的兵。

### 胜负判定
- **炮方胜**：俘获所有兵。
- **兵方胜**：完全困住所有炮，使其无法移动或吃子。
- **和棋**：由于规则限制或局面重复导致的无法推进。

## 部署与运行

### 环境准备
- Python 3.10+
- C/C++ 编译器 (用于编译 Cython 扩展)

### 编译核心模块
```bash
python setup.py build_ext --inplace
```

### 启动程序
```bash
python main.py
```

## 核心技术指标

- **搜索性能**：实测搜索速度约 **2M - 18M NPS** (节点/秒)。
- **残局库**：全集覆盖 3 炮对 4 兵（约 520 万局面），实现必胜局 DTM 单调递减。
- **搜索深度**：迭代加深搜索支持根据时间动态调整深度。
