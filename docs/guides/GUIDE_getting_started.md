## 游戏规则

### 棋子说明

|   棋子   | 数量  | 移动规则                 |
| :------: | :---: | :----------------------- |
| **兵** ● |  15   | 上下左右移动一格（空位） |
| **炮** ◆ |   3   | 移动一格，或隔空跳吃兵   |

### 炮的跳吃规则

```
   . . .        . . .
   . ● ..  →    . . ◆
   . ◆ .        . . .
   
炮前方一格为空，再前方为兵 → 可跳吃
```

### 胜负判定

- **炮方胜**: 吃光所有兵
- **兵方胜**: 困住所有炮（使其无法移动）
- **和棋**: 同一局面出现 3 次

| 模式         | 炮方  | 兵方  | 说明     |
| :----------- | :---: | :---: | :------- |
| **人 vs AI** | 人类  |  AI   | 默认模式 |

| **AI vs AI** |  AI   |  AI   | 观战模式 |
| **人 vs 人** | 人类  | 人类  | 双人对战 |

## 操作指南

### 走子

1. **点击**要移动的棋子（己方棋子会高亮）
2. **点击**目标位置

### AI 计算

- **计算一步**: 让 AI 为当前方计算最佳走法
- **停止计算**: 中断 AI 思考，使用当前最佳结果

### 复盘

| 按钮  | 功能     |
| :---: | :------- |
| `<<`  | 跳到开局 |
|  `<`  | 上一步   |
|  `>`  | 下一步   |
| `>>`  | 跳到最新 |

> [!TIP]
> 复盘时可以从任意历史节点走出新的一步，历史记录会自动分叉。

### 棋谱

- **保存棋谱**: 导出为 JSON 格式
- **加载棋谱**: 导入并复盘

## AI 设置

| 参数         | 默认值 | 说明                 |
| :----------- | :----: | :------------------- |
| **搜索深度** |   8    | 越大越强，但越慢     |
| **时间限制** |  15秒  | 超时自动返回当前最佳 |

> [!NOTE]
> 推荐配置：深度 6-10，时间 10-30 秒

## 常见问题

### Q: 游戏无法启动？

确保 `core/*.pyd` 文件存在，如缺失需重新编译：

```bash
python setup.py build_ext --inplace
```

### Q: AI 计算太慢？

降低搜索深度或缩短时间限制。

### Q: 如何重新编译 Cython？

```bash
pip install cython
python setup.py build_ext --inplace
```
