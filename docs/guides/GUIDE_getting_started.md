# 三炮十五兵 AI版：快速入门指南

本指南帮助用户运行和使用三炮十五兵游戏程序。

---

## 1. 环境要求

- Python：版本要求为 3.10 及以上。
- 依赖库：Tkinter。此库通常由 Python 环境自带。
- 核心模块：必须包含 core 目录下已编译的 pyd 或 so 文件。

---

## 2. 快速开始

### 2.1 运行程序

在项目根目录下执行以下指令：
```bash
python main.py
```

### 2.2 界面布局

界面由棋盘区域、状态面板及控制按钮组成。
- 棋盘区域：显示 5x5 网格及双方棋子。
- 状态面板：显示当前行动方、步数及胜负判定结果。
- 控制按钮：包含新游戏、计算一步、停止计算及复盘导航功能。

---

## 3. 游戏规则

### 3.1 棋子说明

- 兵方：共有 15 枚棋子。初始占据棋盘上方三行。移动规则为向相邻空位平移一格。
- 炮方：共有 3 枚棋子。初始占据棋盘下方中央。具备平移与跨步捕获两种行棋方式。

### 3.2 捕获规则

当炮前方一格为空位，且直线方向第二格为敌方兵方棋子时，炮可跳过空位捕获该棋子。每次行动仅限捕获一枚棋子。

### 3.3 胜负判定

- 炮方获胜条件：吃光所有兵方棋子。
- 兵方获胜条件：困住所有炮方棋子，使其无合法移动。
- 和棋条件：同一局面累计出现三次。

---

## 4. 对战模式设置

用户可在设置菜单中配置以下模式：
- 人机对战：人类玩家对阵算法引擎。
- 算法对阵：两个算法实例互相博弈。
- 双人对战：两名人类玩家线下博弈。

---

## 5. 操作指南

### 5.1 行棋操作

1. 鼠标左键点击己方棋子。选中状态下棋子将高亮。
2. 鼠标左键点击目标空位执行移动。

### 5.2 算法调度

- 计算一步：触发算法引擎为当前行动方寻找最佳走法。
- 停止计算：强制中断当前算法搜索，并直接使用已搜索到的最佳结果。
