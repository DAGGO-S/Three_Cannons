# 三炮困毙最简模式研究

## 1. 核心结论：L型墙角围困 (Minimal L-Trap)

通过对 5x5 棋盘拓扑结构的分析，在满足“所有炮无合法走法”的前提下，**最少仅需 3 枚兵**即可实现对 3 枚炮的全量困毙。

### 1.1 棋盘布局 (3-Soldier Case)
当 3 枚炮在角部形成 L 型靠拢，且 3 枚兵形成外围屏障时，困毙效率最高。

- **炮位置 (Cannons)**: (0,0), (0,1), (1,0)
- **兵位置 (Soldiers)**: (0,2), (1,1), (2,0)
- **FEN**: `cc1s1/cs3/s4/5/5 c`

### 1.2 逻辑验证
- **(0,0) 炮**：相邻格 (0,1) 与 (1,0) 均由己方炮占据，无空位可移动；由于 (0,1) 与 (1,0) 非空，无法作为跳台（Jump 台必须为空），故跳跃吃子路径亦被封死。
- **周边 2 炮**：(0,1) 炮被 (0,0)、(0,2)兵 和 (1,1)兵 三面围堵；(1,0) 炮被 (0,0)、(1,1)兵 和 (2,0)兵 三面围堵。

## 2. 其它典型模式对比

### 2.1 散布围困 (Scattered Traps)
若 3 枚炮分布在不同角落，则每枚炮至少需要 2 枚兵（角部）或 3 枚兵（边缘）来困毙。
- **最小子力开销**：2 + 2 + 2 = **6 枚兵**。
- **评价**：效率较低，常见于残局中后期。

### 2.2 直线封锁 (Straight Line Trap)
- **布局**：3 枚炮在边缘一字排开 (0,1), (0,2), (0,3)。
- **最小子力开销**：需要 (0,0), (0,4), (1,1), (1,2), (1,3) 共 **5 枚兵**。
- **评价**：由于边缘暴露面多，需要的阻挡位点增加。

## 3. 约束说明与分析
为了保证分析的实战价值，生成逻辑引入了以下约束：
- **边缘偏好**：在 3 炮围困中，至少有 2 枚炮位于棋盘边缘（非中心 3x3 区域）。
- **对称性去重**：利用 D4 哈希对称性，仅保留相互独立的旋转/镜像异构体。
