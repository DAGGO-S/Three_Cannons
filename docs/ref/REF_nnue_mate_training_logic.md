# REF_nnue_mate_training_logic.md

## 1. 背景

### 1.1 历史缺陷

NNUE 各历史版本均未显性包含 ±10000（必杀局面）的标注数据。这导致模型在推理阶段不具备静态“看穿”绝杀的能力，绝杀判定完全依赖昂贵的在线搜索深度，缺乏对深层残局知识的离线蒸馏。

### 1.2 初始瓶颈

即便在引入绝杀数据后，模型仍无法有效吸收。经物理分析，传统神经网络训练依赖的 Sigmoid 激活函数在分值达到 ±2000 以上时进入“水平饱和区”，梯度（优化动力）物理消失，导致模型对 ±10000 分产生学习钝化。

## 2. 方法

### 2.1 双引擎混合动力

为兼顾中局稳定性与残局冲击力，物理设计了分段式损失函数

* **中局区 (S < 2000cp)**：维持 Sigmoid 空间回归。保留胜率映射的平滑性，防止模型因过度追求高分而导致中局波动。
* **残局区 (S ≥ 2000cp)**：强制切换至 **原始分值回归 (Raw Score Regression)**。直接拟合物理分值，利用线性梯度打破 Sigmoid 的饱和壁垒。

### 2.2 物理量级对齐

由于分值空间（$10^8$）与胜率空间（$1$）存在物理量级失衡，采用以下物理手段：

* **汇率衰减 **：对分值误差施加 $1,000,000$ 倍物理缩放，确保梯度的可消化性。
* **十倍压迫**：对残局样本施加 10 倍额外权重，物理规定“绝杀错误比中局错误更不可接受”。
* **动力优化**：选用 **AdamW** 优化器并配合 高学习率及权重衰减，快速改写静态评价特征。

## 3. 结果与讨论

### 3.1 训练动态观测

* **收敛物理特质**：Loss 从 25.0 下降至 3.9，未出现震荡或 Loss 爆炸。
* **学习率鲁棒性**：0.02 LR 展现出较好的特性。
