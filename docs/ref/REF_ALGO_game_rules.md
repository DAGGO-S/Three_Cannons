# REF：三炮十五兵进阶游戏规则

本文档完整阐述三炮十五兵的实战行棋与胜负判定规则。

## 1. 棋局与阵营初始化

游戏在 5×5 的方形网格棋盘上进行。分为两大非对称阵营：兵方与炮方。

- 兵方：占据棋盘顶部的三行，共 15 枚棋子。代表符号为实心圆。
- 炮方：放置于棋盘底部的中央三个位置，共 3 枚棋子。代表符号为菱形。
- 缓冲带：倒数第二行开局为空，作为双方博弈空间。
- 行棋先手：默认由炮方率先行动。

## 2. 移动规则

### 2.1 行棋通用准则

- 强制移动：玩家在己方回合必须执行一步合法行棋操作。不允许空步跳过回合。
- 位置独占：每个坐标点仅能容纳一枚棋子。

### 2.2 兵方移动准则

- 可行走法：选择一枚兵，向上下左右直线相邻的空白交叉点平移一格。
- 吃子规则：兵方仅具平移能力。兵方无吃子权。
- 战术目标：通过阵型收缩截断炮的逃生路径。

### 2.3 炮方移动准则

炮具备两种移动方式：

1. 平移：与兵相同，向上下左右直线相邻的空白交叉点平移一格。
2. 隔空跳吃：
   - 炮所在位置向上下左右四个直线方向延伸。若前方一格为空位，且前方第二格为兵，即可跳过空位捕获该兵。
   - 捕获的兵移出棋盘。炮落在目标兵的原位置。
   - 每次行动限吃一子。不支持连跳。

## 3. 终局与胜负判定

### 3.1 认输
任何一方可主动宣告认输，对方即刻获胜。

### 3.2 终局捕获
- 炮方获胜：场上 15 个兵被全部吃光。
- 兵方获胜：轮到炮方行棋时，所有炮无法执行合法移动或跳吃。

### 3.3 局面重复
- 局面判定：棋盘状态与行动方的组合在对局中累计出现三次，判定为平局。

### 3.4 残局计分
在确认平局后进行得分计算：
- 炮方：每吃掉一个兵记 3 分。
- 兵方：每存活一个兵记 2 分。
- 比较双方总得分确定最终胜负。

---
本规则为系统逻辑判定之唯一依据。
