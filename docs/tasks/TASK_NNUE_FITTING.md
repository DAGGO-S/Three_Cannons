## 低置信度讨论 (Low Confidence Discussion)

- **均值回归陷阱 (Mean Regression Trap)**: 由于 97% 的非必杀采样点分布在 1000 分附近，即使模型捕捉到了 3% 的 10000 分信号，也极易在梯度更新中被占绝对多数的样本拉扯回“平庸均值（1000分）”，导致输出值无法冲破阈值。 **【】**
- **标签方向冲突 (Label Conflict)**: 需调查是否存在同一 FEN 在不同数据集里被标为不同分值（如 `score=1000` 与 `final_score=10000` 同时存在），这种梯度信号的互斥会直接导致模型物理性无法收敛。 **【】**
- **评估单调性缺失**: 目前出现的“深度搜索分值萎缩”现象，可能暗示模型不仅没学到 10000 分，甚至在必杀路径上的梯度方向是反向的。这是否是因为模型在训练中过于依赖“子力价值”而非“空间位置”导致的？ **【】**
- **绝杀发现策略与解决思路**:
  1. **[存疑] 极端非平衡采样**：物理剔除残局集中所有 `score < 9900` 的样本，仅保留 1.1 万个真·必杀样本，并将其与主训练集进行 1:1 的混合（而非当前的 1x vs 5x），强行将必杀信号放大到 50% 的占比，观察模型是否能“点火”成功。
  2. **[存疑] 动态权重 Loss (Focal Loss 变体)**：引入权重机制，对 `|score| > 9000` 的样本赋予极大的损失权重（如 100x），迫使模型在牺牲部分平庸局面拟合度的前提下，优先保住必杀临界点。
  3. **[存疑] 准则重定义**：由于 5x5 棋盘极其复杂，目前的 NNUE 层级深度（2层全连接）是否在特征表达能力上存在物理上限，导致无法在保证开局棋力的同时，兼容万分级的残局精度。
