# 三炮十五兵 AI 文档导航索引

> 制定时间：2026-03-22
> 适用对象：首次接入本项目的 AI 代理或开发者。

本文档定义了本项目知识库的物理架构与逻辑工作流规范。严禁修改此规范，除非有更高阶的重构共识。

---

## 1. 物理目录拓扑

知识库采用核心、动态、观测三位一体隔离隔离态。

### 1.1 核心资产
- `specs/`（前缀 `SPEC_`）：静态、不可变的数据协议。包含 FEN 棋盘格式、JSON 存储标准。
- `ref/`（参考资产库）：必须携带以下二级功能前缀：
    - `REF_ARCH_`：宏观架构、模块职责、设计决策。
    - `REF_ALGO_`：算法公式、搜索评估内核、训练逻辑。
    - `REF_INTERFACE_`：API 签名、参数约束、调用序列。
    - `REF_DEBT_`：系统性技术债与路线图。

### 1.2 动态流水
- `proposals/`（前缀 `PLAN_`, `SUGGEST_`）：阶段性提案。结论达成后转化为任务单或抹除。
- `tasks/`（前缀 `TASK_`）：具备量化验收标准的执行单。结案后执行价值提取。

### 1.3 客观观测
- `experiments/`（前缀 `EXP_`）：结构化实验日志。记录对战数据与精度跑分。
- `logs/`：`PROJECT_STATUS.md`（总看板）及项目进度滚动记录。

### 1.4 操作引导
- `guides/`（前缀 `GUIDE_`）：入门指南、环境调优及本文规范详情。

---

## 2. 减熵提炼标准

在任务完结并转化为资产时，强制执行三段式提炼：
1. Fact：最终达成的物理客观指标。
2. Logic：实现逻辑与路径变动。
3. Constraint：新产生的数据或行为约束红线。

---

## 3. 写作铁律
- 坚持冷峻、客观、数据驱动。
- 排除主观疑问。
- 正向事实陈述。
- 单精细度引用。每份文档均为技术溯源基准。
