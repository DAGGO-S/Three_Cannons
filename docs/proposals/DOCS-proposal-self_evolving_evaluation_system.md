# 技术提案：基于模式的自组织深度评估体系

## 1. 核心架构：NNUE (高效可更新神经网络)

### 1.1 算力优化逻辑
针对 Alpha-Beta 搜索对 NPS (Nodes Per Second) 的极高要求，摒弃依赖 GPU 的深度卷积模型。采用浅层全连接网络结构，通过 CPU 矢量指令集实现高速推理。

### 1.2 增量更新机制
利用棋盘移动的局部性特征，仅对发生变动的棋子坐标进行分段计算。该机制确保评估函数的算力开销与传统启发式算法处于同一量级。

## 2. 表征层：5x5 矩阵向量化

### 2.1 输入规范
- **维数**：75 维 (5x5 坐标 × 3 种棋子状态)。
- **编码方式**：采用 One-hot 编码，直接映射原始状态，消除人工特征定义的偏差。

### 2.2 特征自抽取
网络隐含层通过权重分布自动捕捉“炮兵对峙”、“连通域拓扑”及“阵型压迫”等高级抽象概念，无需开发者标定位置评分表。

## 3. 训练策略：数据驱动决策

### 3.1 初始校准 (Ground Truth Alignment)
使用已生成的 3 炮全量残局库作为监督学习集。将定解结果（赢、输、和）作为绝对标签，强制网络建立对必胜/必败模式的基础认知。

### 3.2 自进化学习 (TD-Learning)
针对库外中局局面，采用差分学习机制。
- **预判修正**：对比静态评估分值与深层搜索后的回溯分值。
- **误差反向传播**：通过时间差分偏差不断修正内层权重，实现评估体系的自动更新与迭代。

## 4. 能力泛化与中局迁移逻辑

### 4.1 知识迁移 (Knowledge Migration)
- **底层模式共性**：残局库中的“必胜布局”本质上是状态空间中的全局最优解。NNUE 学习到的不是孤立的 FEN 坐标，而是棋子间的拓扑关系（如“炮架覆盖网”）。这种拓扑关系在子力较多的中局依然具备统计学上的正向收益。
- **锚点效应**：残局库为网络提供了确定性的边界条件。当深度搜索触达残局范围时，计算误差会沿着搜索链条回溯，强制中局的评估分支向正确的残局演化方向收敛。

### 4.2 能力泛化 (Pattern Generalization)
- **特征提取一致性**：隐含层捕捉的特征“基元”（如特定夹角的炮阵、兵阵的屏障效应）具有旋转与平移不变性。这些博弈模式的价值判定逻辑在不同棋局阶段是通用的。
- **动态修正机制**：通过 TD-Learning，系统对比“中局瞬时预判”与“深思熟虑后的搜索结果”。如果某种模式在中局失效，网络将自动调整其在复杂局面下的权重系数，实现策略的自我进化。

## 5. 体系目标

- **消除物质盲区**：通过海量数据训练，识别非离散的子力交换价值。
- **自适应动态权重**：权重随子力残留度自动平滑演进。
- **零人工干预**：实现从“经验主义”向“客观计算”的评估范式转换。
