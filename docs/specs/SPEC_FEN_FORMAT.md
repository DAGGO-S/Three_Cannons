# SPEC: FEN 局面表达规范

本文档定义了三炮十五兵博弈系统中 FEN 字符串的标准扩展格式。

## 1. 字符串结构
FEN 字符串由三个空格分隔的字段组成：
`[棋盘布局] [活动方] [兵方总数]`

### 1.1 棋盘布局
- 按照从第一排到第五排的顺序描述。
- 排与排之间使用正斜杠分隔。
- 棋子标识：
    - `C`：炮。代表炮方棋子。
    - `P`：兵。代表兵方棋子。
- 数字：代表连续的空白交叉点数量。

### 1.2 活动方
- `c`：炮方行棋。
- `p`：兵方行棋。

### 1.3 兵方总数
- 整数：代表盘面上剩余的兵方棋子总数。用于快速判定三重复胜负分界点。

## 2. 标准开局示例
`PPP/PPP/PPP/5/1C1C1 c 15`

## 3. 校验红线
- FEN 字符串必须保证 5x5 的格点拓扑完整性。
- 炮的数量必须为 3。
- 兵的数量范围必须在 1 至 15 之间。
