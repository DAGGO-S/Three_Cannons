# 固定深度性能基准测试

## 目的

在**完全相同的条件**下测量 AI 搜索性能，用于优化前后的 A/B 对比。

## 测试条件

| 参数     | 值                         |
| -------- | -------------------------- |
| 棋盘     | 标准开局                   |
| 执行方   | 炮方（Maximizing）         |
| 搜索深度 | 12（迭代加深，从 1 到 12） |
| 时间限制 | 无（深度为唯一约束）       |
| 置换表   | 每次运行前清空             |

## 用法

```powershell
cd z:\2-Lixinjie\temp_note\test\Three_Cannons
python scripts/bench_fixed_depth.py
```

## A/B 对比流程

1. **记录优化后的结果**（当前代码）：运行脚本，记录总耗时
2. **恢复旧代码**：`git stash` 或 `git checkout HEAD -- core/`
3. **重新编译**：`python setup.py build_ext --inplace`
4. **记录优化前的结果**：运行脚本，记录总耗时
5. **恢复优化代码**：`git stash pop` 或重新编译

## 输出示例

```
  深度  1 | 分数   -290.0 | 耗时   0.001s | 走法 ((4, 1), (3, 1))
  深度  2 | 分数   -405.0 | 耗时   0.003s | 走法 ((4, 2), (3, 2))
  ...
  深度 12 | 分数   -325.0 | 耗时  42.150s | 走法 ((4, 1), (3, 1))

  总耗时:   42.150 秒
  达到深度: 12
```

## 关注指标

- **总耗时**：越短越好
- **各深度耗时增量**：观察深度 N 和 N+1 之间的耗时比（理想约 2-3x）
- **延迟尖峰**：如果某一层突然跳增很多，说明有阻塞操作（如旧版置换表清理）
